# 📚 BookHive – Library Management System

> A modern, lightweight **Laravel** Library Management System built for learning and small library operations.  
> Manage books, authors, members, and borrow/return transactions with ease.

---

## 🚀 Features

✅ **Books Management**
- Add, edit, delete, and search books  
- Track copies, genre, publication date, and availability  
- Assign authors and manage borrow status automatically

✅ **Authors Management**
- Maintain a list of all authors  
- View books written by each author  

✅ **Members Management**
- Register and manage library members  
- Track how many books each member has borrowed  

✅ **Borrow/Return System**
- Issue and return books  
- Automatic late fee calculation ($1.50/day)  
- Book copies and status update automatically  

✅ **Admin Dashboard**
- View total books, members, active borrowings  
- Recent borrow activity log  
- Simple login (email + password)
